# Harvest Buddy til iOS

Native iOS-app til [Harvest Buddy](https://harvestbuddy.cmaintz-site.workers.dev): opgaver,
frostvarsler, haven og høst.

- `swift test` kører pakkens tests.
- `mise run app:build` genererer Xcode-projektet med XcodeGen og bygger appen (macOS med Xcode).
- Debug-builden taler med en lokal dev-server på `localhost:5173`, Release med den deployede app.
